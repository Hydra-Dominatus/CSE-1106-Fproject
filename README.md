# CSE-1106-Fproject
University Library System project:
Program keeps track of students entering and exiting the study room by writing any changed to file change_log.txt. Using a raspberry pi, the program will turn on an LED attached to the pi ONLY when the room is at maximum occupancy, otherwise the LED will remain off. The program also allows the user to change the maximum capacity of the room without issues like overcapacity or the LED not reflecting the change in occupancy.
